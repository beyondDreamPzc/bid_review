## 复现

```powershell
docker compose up --build -d --wait --wait-timeout 180
docker compose exec -T api python -m pytest -q
docker compose exec -T api python -m alembic check
docker compose exec -T api python scripts/quality_smoke.py
docker compose exec -T api python scripts/evaluate_extraction.py
```

集成脚本每次创建独立构造账号和项目，不输出随机密钥，保留测试历史以便检查；退出后受保护接口返回401。评测生成 JSON 默认在 `data/`，不提交或打包。

## 能力边界

没有规则命中不等于无漏字。当前没有 OCR、图片识别、表格重建、多栏阅读顺序验证、自动修复、模型抽取或质量意见强制门槛；不证明企业生产稳定性、负载、高可用或法律合规。规则阈值属于可解释启发式检查，不是有标签大样本上校准的模型置信度。
