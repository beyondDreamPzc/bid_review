# 1.0交付后的验收顺序

截至2026-10-22，单企业Compose版功能代码见[交付清单](交付清单.md)。按用户要求，本轮不继续测试，运行验收由用户启动Docker执行。不得沿用历史版本实测为新功能背书。

1. 按[启动与运维](完整启动与运维.md)构建新镜像、确认0008迁移与全部worker状态。
2. 核对PDF/DOCX版式、MinerU中文/扫描/复杂表格、原文坐标和生成PDF页码。
3. 执行三模板构造检索评估，查看每问来源与真实Recall/MRR；补更丰富长文、跨页表格和无答案问题人工标注。
4. 用户配置真实云模型，先用许可的构造材料检验协议、引用、遗漏、条件/数字保留与人工采纳；不把JSON格式通过当语义准确。
5. 多人验证整改/独立复核、更正、撤销退休、成员交接、密钥/会话与通知；核对过期版本阻断。
6. 验证320/768/1024/1440、键盘焦点、读屏/axe和浏览器报错，发现问题按记录修复。
7. 在隔离数据库/卷做备份恢复演练，重建索引，观察资源与慢查询，确定容量和恢复目标。

若进一步走向正式共享部署，再明确域名/TLS、SSO、多组织、反向代理上传限制、网络隔离、文件扫描、资源限制、审计保留与监控告警目标。它们未因本轮代码交付自动成为已上线经历。
