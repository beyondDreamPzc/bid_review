# 前端设计合同

使用frontend-ui-engineering与frontend-design。参考Ant Design的[工作台](https://ant.design/docs/spec/research-workbench/)、[数据表格](https://ant.design/components/table/)和[空状态](https://ant.design/components/empty/)：借鉴按工作任务组织导航、可筛选清单及有下一步的空态，不复制品牌、文案或现成页面。

## 页面任务

核标是文档证据工作台。核心是让审查人持续看清“当前要求、正式版本、原文证据、下一步负责人”，而非展示技术栈。保留墨青与绿的产品识别；以文件夹式项目导航和左右证据阅读区形成层级。

## 设计约束

- 颜色：主文字#203641，次文字#536873，强调#146b5c，背景#f3f6f7，表面#ffffff，边线#d6e0e3；警告和错误另用语义token。
- 字体：中文使用系统微软雅黑/苹方/思源黑体，英文同系统sans-serif；正文15px，原文阅读16px，辅助信息不小于12px。
- 布局：1440桌面侧栏+工作区；1024/768收紧为横向导航和单列阅读；320窄屏步骤选择，按钮和输入不溢出。文本阅读宽度限制，表格必要时局部横滚。
- 间距：4px基准，控件40/44px高度；4/8px圆角分工，正文区域不堆叠相同统计卡，不使用渐变和重阴影。
- 状态：加载骨架、重试入口、权限解释、有效/过期/待复核文本、成功反馈；只有服务端确认成功才推进业务。
- 交互：URL保留项目和步骤，筛选重置页码，异步结果不得写回另一项目，保留未保存表单；切换和刷新前提醒，提交后移焦到结果。
- 可访问性：跳过导航、单一h1和连续标题层级，显式控件名称、明显键盘焦点、错误定位、aria-live、减少动态效果设置。

## 最终验收

覆盖登录、空项目、资料、质量、AI候选、检索、要求、审查、任务、报告、成员及新增功能。检查控制台、键盘路径、axe及320/768/1024/1440四档尺寸。记录可见结果和工具限制；没有截图时不使用旧图代替。
