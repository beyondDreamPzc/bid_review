## 集成验证发现并修复的问题

1. MySQL 的临时初始化实例会让 localhost socket ping 提前成功。改为使用实际应用账户，通过 TCP 查询目标数据库后判定就绪。
2. 幂等重放路径返回已有结果前没有立即结束锁事务。补上提交并增加回归测试。
3. 同步 SQL 锁等待位于异步上传处理函数内。改为在线程池执行业务事务，避免阻塞事件循环。
4. 集成检查脚本直接执行时未正确定位项目包。已修正入口路径并通过实际 MySQL 检查。

## 明确尚未通过的能力

本次使用 `pdfplumber-probe-v1`。它输出真实页码、bbox、文字及 hash，但尚未验证表格语义，也没有运行 OCR。因此产物始终是 `NEEDS_REVIEW`，`formal_review_ready=false`。

Docling 正式解析、DOCX 转换、模型抽取、Milvus 检索、逐项业务审查、更正影响、要求基线、前端工作台和业务人员验收仍在后续计划中。

当前测试依赖出现一条 Starlette 对 httpx TestClient 的弃用提示；测试全部通过。后续升级测试客户端时须单独锁定并回归，不把这次测试解释成所有依赖长期兼容。
